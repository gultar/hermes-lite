Take a screenshot and look at it: the screen the user is on (default), a window by name (its title or app class, e.g. 'firefox', 'Strategy Game'), or a web page rendered headless from a URL (http://localhost:3000 — best for checking a web app you are building: no need for the user's browser). The image is shown to you once, after this call; note what you see in your next reply. Only the user's visible screen can be captured — windows on hidden workspaces cannot.
