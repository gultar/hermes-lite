Read GitHub without a browser. action=search: find repositories (query). action=readme: a repo's README, optionally only the sections matching query. action=file: a file (path, optional ref) or a folder listing; a file too big to show at once returns its outline (classes, functions and their line ranges) and first lines, then any range with offset/limit. action=releases: the latest release notes — check them when an API seems to have changed. action=code_search: usage examples across GitHub (needs the user's gh login). Results are short; pass query to get only the relevant part.
