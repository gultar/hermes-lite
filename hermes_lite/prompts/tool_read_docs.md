Read a library's current documentation, cut to what you asked about. Give a docs 'url', or a 'library' name to find its docs automatically, plus a 'query' naming the API or topic. Uses the project's llms.txt (docs written for AI models) when it exists, otherwise the page itself. Use it before relying on remembered APIs, and when an error suggests the API changed.
